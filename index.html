autoshorts

Ferramenta pessoal para gerar vídeos curtos e publicá-los no meu próprio canal do YouTube.

O autoshorts roda no meu computador. A partir de um tema, ele monta um vídeo curto com narração e imagens de bancos gratuitos (como o Pexels) e envia o vídeo para o meu canal usando os Serviços de API do YouTube.
