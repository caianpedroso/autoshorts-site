Política de Privacidade — autoshorts

Última atualização: 6 de outubro de 2026

1. O que é o autoshorts

O autoshorts é uma ferramenta pessoal, executada no computador do próprio usuário, que gera vídeos curtos e os publica no canal do YouTube desse mesmo usuário. Não existe um serviço on-line nem servidores do autoshorts: tudo roda localmente.

2. Serviços de API do YouTube

O autoshorts usa os Serviços de API do YouTube. Ao usar o autoshorts, você concorda com os Termos de Serviço do YouTube. O tratamento de dados pelo Google é regido pela Política de Privacidade do Google.

3. Dados acessados

Com a sua autorização (Google OAuth), o autoshorts pode:

  • enviar vídeos para o seu canal do YouTube (permissão youtube.upload);
  • ler informações básicas do canal, como o nome, para confirmar qual canal foi autorizado (permissão youtube.readonly).

O autoshorts não acessa e-mails, contatos, comentários, histórico de visualização ou dados de outros usuários.

4. Como os dados são usados e guardados

  • O token de autorização fica salvo apenas no seu computador, no arquivo token.json, com acesso restrito ao seu usuário.
  • Títulos, descrições e identificadores dos vídeos enviados ficam num banco de dados local (autoshorts.db) para evitar envios duplicados.
  • Nenhum desses dados é enviado ao desenvolvedor ou a servidores do autoshorts.

5. Compartilhamento

O autoshorts não vende nem compartilha dados pessoais. Os vídeos e seus metadados são enviados somente ao YouTube. O tema e o roteiro de cada vídeo são enviados ao provedor de inteligência artificial configurado pelo próprio usuário (por exemplo, a OpenAI) para gerar o texto; nenhum dado da conta do YouTube é enviado a esse provedor.

6. Cookies

O autoshorts não usa cookies nem ferramentas de rastreamento.

7. Como revogar o acesso e apagar os dados

  • Revogue a autorização a qualquer momento em myaccount.google.com/permissions ou nas configurações de segurança do Google.
  • Para apagar os dados locais, exclua os arquivos token.json e autoshorts.db da pasta do autoshorts.
